# YesterMe website

The website of YesterMe, a one-handed puzzle game: https://yesterme-game.github.io

| Page | Path |
|---|---|
| Home (English and Turkish) | `/` |
| Privacy Policy | `/privacy/` |
| Terms of Use | `/terms/` |
| Gizlilik Politikası (Turkish) | `/tr/gizlilik/` |
| Kullanım Şartları (Turkish) | `/tr/kullanim-sartlari/` |

The game's Settings and the store listings link to the privacy policy and the terms. When one of them changes, change both languages and the "Last updated" date together.

Every page uses `style.css`. The wordmark is set in Sora Bold, served from `fonts/` under the SIL Open Font License (`fonts/OFL.txt`). The site uses no cookies, no analytics and nothing from other hosts.
